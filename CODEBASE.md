# Codebase reference

This document maps **every part** of the trimmed project: what it does, what it reads/writes, and how it connects to the rest.

---

## Root layout

| Path | Purpose |
|------|---------|
| `app.py` | Flask server: static UI + `POST /api/predict` for scoring a single review. |
| `requirements.txt` | Python dependencies (Flask, sklearn, NLTK, spaCy, textstat, matplotlib). |
| `README.md` | User-facing overview, quick start, pipeline narrative. |
| `README_PIPELINE_DIAGRAM.md` | Mermaid diagram of the inference pipeline only. |
| `CODEBASE.md` | This file — file-by-file reference. |
| `data/` | **Only** `amazon_reviews_training.csv` (labeled Amazon reviews used for training). |
| `artifacts/` | Generated by training: `ensemble.joblib` (fitted models + weights), `ensemble_meta.json` (summary). |
| `reports/training/` | Generated by training: `training_report.html`, PNG charts, `training_metrics.json`. |
| `scripts/train_pipeline.py` | CLI entry: train models, write artifacts + training report. |
| `src/fake_review_detection/` | Package root: `config/`, `stages/` (numbered pipeline), `__init__.py` re-exports. |
| `src/fake_review_detection/stages/README.md` | One table describing each stage folder (for presentations). |
| `web/templates/index.html` | Review form + results panels (calls `/api/predict`). |
| `web/static/style.css` | Dark theme styles for the UI. |

Nothing else is required for the app or training. Older notebooks, Yelp exports, and duplicate CSVs were removed to keep the repo minimal.

---

## `app.py`

- Adds `src/` to `sys.path`, imports `fake_review_detection`.
- **Routes:** `GET /` → `index.html`; `POST /api/predict` → JSON body parsed, `predict_explain()` called, JSON response.
- Downloads NLTK VADER lexicon on first predict if needed.
- **Does not** train models; expects `artifacts/ensemble.joblib` to exist (run `scripts/train_pipeline.py` first).

---

## `scripts/train_pipeline.py`

- Ensures `data/amazon_reviews_training.csv` exists.
- Calls `train_from_csv()` with `write_reports=True` and `reports_dir=REPORTS_DIR`.
- Prints JSON `TrainReport`, a **step table** (validation accuracy / F1 per stack stage + dF1), paths to artifacts and `reports/training/`.

## Package `src/fake_review_detection/`

### `__init__.py`

- Re-exports **`train_from_csv`**, **`predict_explain`**, **`load_ensemble`**, **`TrainReport`**, **`EnsembleWeights`**, and common **`config`** symbols for `app.py` / scripts.

### `config/settings.py` (import as `fake_review_detection.config`)

- Paths: **`ROOT`**, **`TRAINING_CSV`**, **`ENSEMBLE_PATH`**, **`META_PATH`**, **`REPORTS_DIR`**, etc.
- **`TABULAR_FROM_CSV`**: columns that must exist in the training CSV.
- **`TABULAR_DERIVED_FEATURES`**: stylometry + diversity + VADER pos/neg + sentence stats (computed from text at train and inference).
- **`TABULAR_FEATURES`**: concatenation of the two lists (tabular LR input order).

### `stages/stage_01_preprocess/normalize.py`

- **`normalize_review_text`**, **`normalize_title`**: preprocessing before features and TF-IDF.

### `stages/stage_02_features/linguistic.py`

- spaCy POS, VADER compound, textstat FRE, **`extract_tabular_row`** (CSV-aligned metadata + NLP; no raw star count column).

### `stages/stage_02_features/derived_text.py`

- **`compute_derived_features(raw, normalized)`**, **`augment_derived_dataframe(df)`**: punctuation/caps/digits, TTR-style ratio, mean words per sentence, VADER pos/neg.

### `stages/stage_03_heuristics/rules.py`

- Rule scores + **`aggregate_heuristic`**; includes marketing-lexicon density and punctuation-heavy high-rating cue.

### `stages/stage_04_text_model/tfidf_pipeline.py`

- **`FeatureUnion`** char + word TF-IDF; **`fit_best_tfidf`** chooses LR vs calibrated LinearSVC on validation macro-F1.

### `stages/stage_05_tabular_model/tabular_pipeline.py`

- **`build_tabular_pipeline`**: `MinMaxScaler` + `LogisticRegression`.

### `stages/stage_06_ensemble/blend.py`

- Logit blend helpers, **`tune_weights`**, **`tune_logit_bias`**, **`MIN_HEURISTIC_WEIGHT`**, dataclasses **`EnsembleWeights`**, **`TrainReport`**.

### `stages/stage_06_ensemble/train_predict.py`

- **`train_from_csv`**, **`load_ensemble`**, **`predict_explain`**, **`_tabular_explanations`**.

### `stages/stage_07_evaluation/metrics.py`

- **`metrics_from_probs`**: accuracy, macro F1, ROC-AUC, confusion counts.

### `stages/stage_07_evaluation/report.py`

- **`StepResult`**, **`write_training_report`** (JSON + PNG + HTML).

### `stages/stage_08_output/verdict.py`

- **`verdict_from_probability`**, **`binary_class_from_probability`**.

## `web/templates/index.html`

- Form: review text, title, stars, verified, optional product aggregates.
- Fetches `/api/predict`; shows headline verdict + probability; explanations in **`<details>`** sections (ensemble, heuristics, tabular contributions, feature JSON, about).

---

## `web/static/style.css`

- Dark layout variables, cards, tables, meter, buttons — presentation only.

## Data flow summary

1. **Training:** `data/amazon_reviews_training.csv` → `train_from_csv` → `artifacts/ensemble.joblib` + `ensemble_meta.json` + `reports/training/*`.
2. **Inference:** User input → `app.py` → `predict_explain` → reads `ensemble.joblib` → JSON → browser.

---

## Extending safely

- **New CSV tabular columns:** add to **`TABULAR_FROM_CSV`** in `config/settings.py`, extend **`extract_tabular_row`**, retrain.
- **New derived-from-text columns:** extend **`TABULAR_DERIVED_FEATURES`** and **`compute_derived_features`**, retrain.
- **Change blending:** edit `stages/stage_06_ensemble/blend.py` (grid, min heuristic, bias search).
- **New charts:** extend `stages/stage_07_evaluation/report.py` and call from **`train_from_csv`**.
- **Different training file:** change **`TRAINING_CSV`** in `config/settings.py` or pass another path into **`train_from_csv`** from a forked script.
